Privacy policy

Last updated October 26 2026.

The short version

We do not collect your chats. We do not use cookies. We do not run analytics. This site has no account system and no database.

What happens to your text

When you press the button this page sends your text to Ollama on your own computer. The address is localhost. The text never travels to our servers or to any other server. The page enforces this with a content security policy that only allows connections to localhost.

The page keeps your text in memory only. Reloading the page or pressing Wipe everything removes it. Files you open are read inside the page and are not uploaded.

What the host can see

The site is served by a static hosting provider. Like any web host it may keep standard server logs such as your IP address and the time of the request. We do not combine these logs with anything and we do not read your chats because we never receive them.

The command line version

The Python script in the repository also runs on your computer. It sends nothing anywhere by default. Two optional features exist and both stay off until you set a key yourself.

Sentry tracing sends timing and token counts for each model call. Message text and file names are not added. Local variables and personal data are switched off in the code.

ElevenLabs speech sends the final two line digest to ElevenLabs so that it can create audio. This only happens when you pass the speak flag and set a key. Their own privacy policy applies to that text.

Your choices

Use the tool with the network unplugged if you want full certainty. Run the page from the repository folder. Do not set the optional keys.

Children

This tool is not directed at children under 13.

Changes and contact

If this policy changes the date above will change. To ask a question open an issue on the project repository on GitHub.
