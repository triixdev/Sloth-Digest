Two lines. Every morning.

SlothDigest reads your group chats and tells you what happened and what to do today. It runs on your own computer with the open model Gemma. Your messages stay on your machine.

Checking for Ollama

You can also open text files from your disk. They are read in this page only.

Your digest

Your two lines will appear here.

What you get

Private
Your chats go from this page straight to Ollama on your own computer. No server of ours ever receives them.
Free
No account. No key. No usage fee.
Offline
Run it from the repository folder and it works with the network unplugged.
Swappable
Pick any model you have installed. Gemma 3 is the default choice.
Safe output
Results appear as plain text. Instructions hidden inside a chat are treated as data.
Traceable
The command line version can send timing and token counts to Sentry. Message text is never added to traces.

Run it in three steps

  1. Install Ollama from ollama.com and run ollama pull gemma3:4b
  2. Open this page in Chrome or Edge or Firefox. Safari blocks the link to your computer.
  3. If the status above says blocked then allow this site and restart Ollama: 
    OLLAMA_ORIGINS=https://your-site ollama serve

To skip the allow step run the page locally from the repository folder. Ollama trusts local addresses by default.

python3 -m http.server 8000 --directory site
open http://localhost:8000
